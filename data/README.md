# Data provenance

The sample file follows the public UCI Online Retail schema and preserves representative seed rows from the dataset. UCI describes the source as 541,909 transactions from a UK online retailer between 2010-12-01 and 2011-12-09, licensed CC BY 4.0:

https://archive.ics.uci.edu/dataset/352/online%2Bretail

ShelfSignal adds a small, explicit synthetic overlay in the browser for branch stock, supplier lead time, expiry, and policy. Those fields are not present in the UCI file and are not presented as pharmacy data.
