# Competitive differentiation

Research covered first-party descriptions of Linear Intake, GitHub Copilot code review, Granola, Notion AI Autofill, Intercom procedures, Sierra Horizon, Retool AI agents, and RELEX planning. The research notes are grounded in their official product or documentation pages.

Common patterns are chat with buttons, AI-filled database properties, dashboards with an AI insight panel, and generic escalation that drops context. Those patterns improve an existing interface but keep the user responsible for scanning and framing the work.

ShelfSignal differs in four ways:

1. **Exception-first:** it wakes up on the costliest-to-ignore operational condition instead of waiting for a prompt.
2. **Role-specific:** the surface is for a pharmacy operations lead making a replenishment decision, not a general AI assistant.
3. **Action-bound:** it ends in a staged, reversible PO or branch transfer with a human approval gate.
4. **Correction-native:** a stale count or promotion spike changes the plan in place and leaves the recovery path visible.

The real-data bonus is addressed with the public UCI Online Retail transaction schema. Synthetic branch inventory and supplier fields are intentionally disclosed rather than disguised as public data.
